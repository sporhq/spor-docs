This section is under construction. It will document every `spor` verb with
its flags, aliases, and a badge for the mode it runs in (local, remote, or

The `spor` command line is the shell surface for the graph. One binary serves
both modes: each verb resolves local-versus-remote per call, so scripts and
habits carry over when a personal graph grows into a team one.
